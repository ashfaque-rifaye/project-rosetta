Install Rosetta on a Fire TV

The TV app below is already connected to the live AWS backend and the public DEMO family (Mom, Dad, Arjun in Grade 3, Meera in Grade 1). Install it, then use the parent and kid phone pages to play the family's part.

1 · On a Fire TV (Fire OS)

  1. On the Fire TV: Settings → My Fire TV → Developer options (tap About 7 times if it's hidden) and turn on Install unknown apps for Downloader.
  2. Install the free Downloader app from the Amazon Appstore.
  3. In Downloader, type dr8w3l96syzm7.cloudfront.net/downloads/rosetta-tv-demo.apk and choose Install.
  4. Optional, for the 3D Quiz Night: repeat with dr8w3l96syzm7.cloudfront.net/downloads/rosetta-quiz-night.apk.

Or with ADB: turn on ADB debugging in Developer options, then from a computer on the same network:

adb connect <fire-tv-ip>:5555
adb install rosetta-tv-demo.apk
adb install rosetta-quiz-night.apk   # optional

2 · Or on the Android TV emulator (accepted by the hackathon FAQ)

  1. Android Studio → SDK Manager → install system-images;android-36;android-tv;x86_64 (Fire OS 16 is Android 16).
  2. Device Manager → create a Television 1080p device on that image and start it.
  3. Download both APKs above and run adb install rosetta-tv-demo.apk (and the Quiz Night APK).

Emulator keys: arrows = D-pad, Enter = select, Esc = Back.

Five minutes with the DEMO family

  1. TV: Rosetta opens on the living house. Move down the Quest Board; the camera follows each task to its room. Press UP for Arjun's and Meera's Progress or the Parents QR.
  2. Parent phone: open the parent page, sign in as Mom with the demo PIN 2468, and tap Unlock TV time now. The TV portal opens; Lock it again resets it.
  3. Homework: on the TV open Fractions homework. On the kid page pick Arjun and photograph any worksheet. In about 15 seconds the ✦ AI Tutor marks it on the TV, then sets practice.
  4. Honesty: send a photo of something else and Rosetta says what it actually sees.
  5. Daily task: on the kid page, send a voice note for Read 10 pages. It becomes a memory on the parent page.
  6. Pocket money: add a small wish on the parent page; when a child has saved enough they tap Ask Mom & Dad on the kid page and Mom approves. The TV's Treasure screen updates.
  7. Quiz Night: bottom bar → Quiz Night. Rosetta writes 8 questions for the two children and opens the 3D game.

Everything is shared live, so another tester may be using the DEMO family too. Start the family over is at the bottom of the parent page.

How it runs

Serverless on AWS, in one AWS CDK stack: Amazon CloudFront and S3 for these pages, Amazon API Gateway and AWS Lambda for the API, a Strands Agents crew on Lambda with Amazon Bedrock (Amazon Nova 2 Lite) for every AI call, Amazon Polly for the Keeper's voice and Amazon Transcribe for kids' voice notes, Amazon DynamoDB for each family, S3 events for photo and voice uploads, Amazon EventBridge for nudges, and Amazon SES / SNS for parent alerts.
